# 外部脳スターターキット

メモの山を「AIが2秒で答える外部脳」に変えるための最小セットです。
Obsidianを想定していますが、Markdownが書けるメモアプリなら何でも動きます。

## 中身

```
00_INDEX.md            … 索引(全ノートの入り口になる地図)。1枚だけ置く
templates/原子ノート.md   … ノートの雛形(1ノート=1事実)
templates/運用ルール.md   … 外部脳の設計5原則と週次メンテの手順
```

## セットアップ(5分)

1. Obsidianで保管庫(Vault)を作る(既にあるならそれでいい)
2. `00_INDEX.md` を保管庫の一番上に置く
3. `templates/` の2枚を保管庫の `templates/` フォルダに置き、
   設定 → テンプレート → テンプレートフォルダを `templates/` に指定する
4. 今日から書くメモは全部「原子ノート」の雛形で書く
5. 書いたら `00_INDEX.md` に1行足す。これだけ

過去のメモは移行しなくていい。**今日から先のメモだけ**この構造にすれば、
1〜2週間で「検索が効く領域」が生まれて、そこから外部脳になっていきます。

## AIに読ませる

外部脳の完成条件は「AIがこの保管庫を歩けること」です。

- **ChatGPT / Claude(チャット)**: 質問するとき、関連ノートと `00_INDEX.md` を
  そのまま貼る。索引があるとAIは「どこを見るべきか」から自分で判断できる
- **Claude Code / Cowork**: 保管庫のフォルダを作業ディレクトリとして渡して
  「INDEXから辿って答えて」と言うだけ。これが一番強い
- コツは1つ。**AI用に特別な整理をしないこと。**
  人間が思い出せる構造と、AIが検索できる構造は、ほぼ同じです

## なぜこの構造なのか

詳しくは `templates/運用ルール.md` に書きましたが、要点は1行です。

**溜めた量は資産じゃない。歩ける構造だけが資産。**
