# 依頼: ByakuyaAI ランディングページの視覚強化
あなたはWebフロントエンドのトップデザイナー兼エンジニアです。以下はNext.js 15(App Router)+ Tailwind CSS 4のランディングページ全ソースです。
## ゴール
このLPを「AI自動化の専門家」にふさわしい、3D・モーション豊かな最高級の見た目に強化する。参考水準: Awwwards受賞級のSaaS LP。
## 技術制約
- Next.js App Router + Tailwind 構成を維持。ライブラリ追加可: three / @react-three/fiber / @react-three/drei / framer-motion / gsap(npm installは受け取り側で実施するので使ってよい)
- 出力は必ず「ファイル単位の完全なコード」で。断片・差分・「...既存のまま」は禁止。変更した全ファイルと新規ファイルを、ファイルパス見出し付きで出力すること
- ルーティング・リンク先URL・フォーム送信先・meta/OGP/SEO・法務ページへのリンクは一切変更しない
- 文言(コピー)は原則維持。視覚・モーション・レイアウトの強化に集中
- モバイル(375px)での崩れ禁止・Lighthouse Performance を大きく損なわない(3Dは遅延ロード)
## 出力の順番
1) 変更方針の要約(10行以内) 2) 追加npm依存のリスト 3) 全ファイル(パス見出し+完全コード)

function TabButton({
  active,
  premiumActive,
  onClick,
  label,
  price,
  highlight,
  compact,
}: {
  active: boolean;
  premiumActive: boolean;
  onClick: () => void;
  label: string;
  price: string;
  highlight: boolean;
  compact: boolean;
}) {
  const sizeClasses = compact
    ? "min-w-[110px] flex-row gap-1.5 rounded-full px-3 py-1.5 sm:min-w-[140px] sm:px-4 sm:py-2"
    : "min-w-[160px] flex-col gap-1 rounded-2xl px-6 py-4 sm:min-w-[220px] sm:gap-1.5 sm:px-10 sm:py-5";

  const base = `relative flex items-center justify-center font-bold transition-all duration-300 ${sizeClasses}`;

  const labelClass = compact ? "text-xs sm:text-sm" : "text-base sm:text-lg";
  const priceClass = compact
    ? "text-xs font-black opacity-90"
    : "text-sm font-black opacity-90 sm:text-base";

  if (active && highlight) {
    return (
      <button
        type="button"
        onClick={onClick}
        className={`${base} ${
          compact ? "" : "neon-pulse scale-105"
        } bg-black text-[var(--brand-orange-light)] ring-2 ring-[var(--brand-orange)]`}
      >
        <span className={labelClass}>{label}</span>
        <span className={priceClass}>{price}</span>
      </button>
    );
  }

  if (active && !highlight) {
    return (
      <button
        type="button"
        onClick={onClick}
        className={`${base} ${
          compact ? "" : "scale-105 shadow-xl shadow-orange-200"
        } bg-[var(--brand-orange)] text-white shadow-lg`}
      >
        <span className={labelClass}>{label}</span>
        <span className={priceClass}>{price}</span>
      </button>
    );
  }

  const inactiveStyle = premiumActive
    ? "border-2 border-white/25 bg-white/5 text-white/75 hover:bg-white/15 hover:text-white hover:border-white/50"
    : "border-2 border-[var(--brand-border)] bg-white text-[var(--brand-gray)] hover:border-[var(--brand-orange)] hover:text-[var(--brand-ink)] hover:bg-[var(--brand-cream)]";

  return (
    <button
      type="button"
      onClick={onClick}
      className={`${base} ${inactiveStyle}`}
    >
      <span className={labelClass}>{label}</span>
      <span className={priceClass}>{price}</span>
    </button>
  );
}
